# OSINT Agent Tool Requirements
#
# The platform degrades when tools are missing. That is useful for passive OSINT,
# but it is bad if you expect real bug detection. For high-signal bug bounty
# results, install the "minimum real scanner" set first, then the full set.


## 1. Python Runtime

python>=3.10
pipx
go>=1.22
git
curl
openssl
dig
whois

Install Python dependencies:
    python3 -m pip install -r requirements.txt

Install the full package extras when using setup.py:
    python3 -m pip install -e ".[full]"


## 2. Browser Runtime

# Required for browser-rendered crawling and CONFIRMED reflected/DOM XSS checks.
playwright>=1.45
chromium-for-playwright

Install:
    python3 -m pip install playwright
    python3 -m playwright install chromium


## 3. Minimum Real Web Scanner Set

# Without these, the platform still runs, but coverage is shallow.

nuclei
httpx
katana
gau
ffuf
dalfox
sqlmap
arjun
paramspider
whatweb
interactsh-client

macOS / Homebrew where available:
    brew install nuclei httpx ffuf sqlmap whatweb

Go tools:
    go install github.com/projectdiscovery/katana/cmd/katana@latest
    go install github.com/lc/gau/v2/cmd/gau@latest
    go install github.com/hahwul/dalfox/v2@latest
    go install github.com/projectdiscovery/interactsh/cmd/interactsh-client@latest

Python CLI tools:
    pipx install arjun
    pipx install paramspider

Nuclei templates:
    nuclei -update
    nuclei -update-templates

## 10. OOB / Blind Vulnerability Infrastructure

# Required for blind SSRF, blind XSS, blind SQLi, XXE, and command-injection
# callback confirmation.

interactsh-client
custom-callback-domain

Install:
    go install github.com/projectdiscovery/interactsh/cmd/interactsh-client@latest

Configure one of these in config.yaml:
    oob.callback_domain
    oob.server_url
    oob.poll_url
    oob.token
